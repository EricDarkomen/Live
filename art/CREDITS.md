# Character art credits

Most of the art in this game is pixel art from the **Liberated Pixel Cup**
community. Each sheet in `art/sprites/` comes from one source, and is pinned —
by commit where it was built from a repository, by sha256 where it was built
from a downloaded file, and by the sha256 of its own bytes where it arrived
whole and this project never rebuilt it:

- `art/sprites/sanitary.png` — from `art/src/` in this repository (LICENSE part 3)
- `art/sprites/world.png` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`
- `art/sprites/cars.png` — [Top Down Cars Sprite Pack, by tokka](https://tokka.itch.io/top-down-car), shipped whole and pinned by sha256 (LICENSE part 4)
- `art/sprites/town.png` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`
- `art/sprites/faces.png` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`
- `art/sprites/streets.png` — [LPC Modern Streets](https://opengameart.org/content/lpc-modern-streets), each file pinned by sha256
- `art/sprites/wood.png` — [LPC Wooden Furniture](https://opengameart.org/content/lpc-wooden-furniture), each file pinned by sha256 (LICENSE part 3)
- `art/sprites/victorian.png` — [LPC Victorian Town Decorations](https://opengameart.org/content/lpc-victorian-town-decorations), each file pinned by sha256 (LICENSE part 4)
- `art/sprites/frontage.png` — [LPC Windows & Doors](https://opengameart.org/content/lpc-windows-doors), each file pinned by sha256 (LICENSE part 3)
- `art/sprites/roofs.png` — [LPC Roofs](https://opengameart.org/content/lpc-roofs), each file pinned by sha256 (LICENSE part 3)
- `art/sprites/parts/` — [ElizaWy/LPC](https://github.com/ElizaWy/LPC), commit `f07f7f5892e67c932c68f70bb04472f2c64e46bc`; one PNG per component of the character creator

**The original artwork has been modified**: layers were composited into single
characters, recoloured using the LPC palette definitions, cropped to the
standing, walking, running, sitting and one-handed combat frames, and packed
into a sheet per source project — or, for the character creator, a file per
component.

**The beachwear is derived from the same parts**: the bikini tops, bikini
bottoms, trunks, shorts, tank tops and open shirts in `art/sprites/parts/`
(the entries named `Swim …` in `art/sprites/manifest.js`) were cut from the
LPC T-shirt and trouser parts listed above, frame by frame, and recoloured
from the T-shirt palettes. They carry the licence of the parts they were cut
from.

**Standing of the `cars.png` attribution.** That sheet did not arrive
through `tools/sheets/`, so there is no pinned archive to re-download and no
upstream credits file to re-parse. It carries no PNG metadata of any kind, and
its source page is refused by the network this project's builds and sessions run
behind — so its author and its licence were **reported by the project owner**
from that page rather than read from in here. What is checked mechanically is
only that the bytes have not changed: `tools/lib/pinned.mjs` records their
sha256 and the build stops if it moves. If the attribution is wrong it should be
corrected rather than removed — the art is licensed, and the obligation is to
credit the right person. See LICENSE part 4.
