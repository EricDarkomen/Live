# Fonts

The interface's two typefaces, bundled so the game works offline and from
`file://` without a request to a font service.

| File | Font | Licence |
| --- | --- | --- |
| `fredoka.woff2` | [Fredoka](https://github.com/hafontia/Fredoka-One) — Copyright 2016 The Fredoka Project Authors | SIL Open Font License 1.1 — [`OFL-Fredoka.txt`](OFL-Fredoka.txt) |
| `nunito.woff2` | [Nunito](https://github.com/googlefonts/nunito) — Copyright 2014 The Nunito Project Authors | SIL Open Font License 1.1 — [`OFL-Nunito.txt`](OFL-Nunito.txt) |

Both are the unmodified Latin subsets of the variable fonts as served by
Google Fonts. They are **not** covered by the game's own licence: the OFL
lets them be used, bundled and redistributed with any software, and requires
that they are not sold on their own.
